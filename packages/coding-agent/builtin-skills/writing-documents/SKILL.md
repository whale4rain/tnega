# Writing documents

Shape the document around the reader's purpose and the evidence provided.

1. Establish audience, intended action, format, tone, and length from the request and existing material. Ask only for missing information that would change the result; use reasonable defaults for routine presentation choices.
2. Extract the central message and supporting facts. Keep quotations and citations attached to their sources. Mark missing evidence instead of filling gaps with invented details. Preserve names, dates, quantities, and the author's intended position when revising.
3. Draft in the user's language. Lead with the answer, recommendation, or purpose; give each paragraph one job. Use headings and lists where they make navigation easier, and include an explicit decision or next action when the document requires one.
4. Check factual fidelity, internal consistency, repetition, and the requested scope. For an executive memo, verify that the recommendation, rationale, uncertainties, and requested decision are all present.
5. If saving an artifact, use Workspace file tools for text. For `.docx`, inspect available `office_create` or `office_edit` schemas, then verify the saved content with `office_inspect` and `office_read`. Visual layout requires an available preview or renderer; content inspection alone does not prove layout quality.

Deliver the artifact path and a concise account of any remaining gaps. This skill does not grant permission to publish, email, or submit the document externally.
