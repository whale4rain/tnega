# Weather · Tnega 的状态设计语言

日期：2026-10-01。总规范见 [`tnega-design.md`](tnega-design.md)。

Tnega 的 Agent 是一朵小云。原有的形象语言不变——一块扁平、饱和的软形状加两只白眼睛——天气是叠在它之上的第二层语言：**云周围的天在做什么，就是 Agent 在做什么**。品牌标志就是这朵带眼睛的云。

## 原则

1. **一种天气只有一个意思。** 同一个符号出现在头像、会话列表或状态行里，不需要图例。
2. **最紧急的信号优先。** 等你（雪）> 出错（雷暴）> 正在发生的事 > 环境（雾）> 余韵（彩虹）。
3. **同一套扁平语言。** 实心色块，无描边，少量粗壮的元素；16px 也要认得出来。角色本身只缩小让出天空，形状、颜色与眼睛不变。
4. **表情只是微调。** 下雪时抬眼看你，雷暴时眯眼，彩虹时笑眼。不加嘴、不加腮红。
5. **动效是轻微的循环，并且可以完全停下。** `prefers-reduced-motion` 下所有天气静止。
6. **颜色就是天气。** 成功色是晴、警告色是太阳、危险色是雷暴；天气色来自 `--wx-*` token，深浅主题各有一套。

## 已实现：Agent 状态

| 天气 | 含义 | 何时出现 | 画法 |
| --- | --- | --- | --- |
| 晴 clear | 就绪 | 空闲（大头像上作为默认展示） | 角色右上方的太阳，光芒缓慢旋转 |
| 多云 cloudy | 思考 | 模型正在生成，没有工具在跑 | 身后一团小云漂移，角色轻轻浮动 |
| 小雨 drizzle | 工作 | 一个工具或一个子 Agent 在运行 | 两滴雨 |
| 大雨 rain | 忙碌 | 两个以上同时在运行 | 四滴更快的雨 |
| 雪 snow | 等你 | 有审批或问题等用户回答 | 雪花飘落，角色抬眼——"冻住了，等你开口" |
| 雨夹雪 sleet | 重试 | 瞬时失败后正在重试 | 雨滴与雪花交替 |
| 雷暴 storm | 出错 | 本轮失败、子 Agent 失败 | 角色变暗，下方闪电，眯眼 |
| 雾 fog | 上下文将满 | 上下文使用 ≥ 85% | 三条雾带横过角色，细节可能被压缩 |
| 彩虹 rainbow | 完成 | 一轮成功结束后的约 3 秒 | 三色拱桥画出，笑眼 |
| 红色精灵 sprite | 派出帮手 | 正在启动子 Agent | 粉色触须从云顶向上升起——高层大气里，精灵正是从雷暴云顶向上放电 |

实现：`apps/web/src/lib/weather.ts`（映射与优先级）、`components/WeatherLayer.tsx`（图形）、`components/AgentAvatar.tsx`（叠加与表情）、`styles/project.css`（动效）。开发服务的 `/weather.html` 是校准页：每种天气在 72px、26px、20px 与深浅主题下的样子。

会话主 Agent 与 Project 协调者都画成强调色的云；Thread 与子 Agent 保留原来的随机形状与颜色，天气同样适用于它们。

## 配色：天空

- **浅色 · 白昼**：带一点蓝的冷调纸面（`#f4f6f8`），石板色正文，晴空蓝强调色（`#2f6fd0`）。
- **深色 · 夜空**：低饱和蓝灰（`#0f131a` / `#171c26` / `#1f2531`），月光蓝强调色（`#8ab4f8`）。完整取值与对比度底线见 [`tnega-design.md`](tnega-design.md)。
- 天气色：太阳 `--wx-sun`、雨 `--wx-rain`、雪 `--wx-snow`、雷暴 `--wx-storm` 与闪电 `--wx-bolt`、雾 `--wx-fog`、精灵 `--wx-sprite`、彩虹三色 `--wx-rainbow-1..3`。

桌面端标题栏默认色、favicon 与安装包图标（`apps/desktop/build/icon.svg` → `scripts/render-icon.mjs`）同步更新。

## 可以继续扩展的角色

天气能承载的不止头像。以下是同一套语义可以自然延伸到的地方，按价值排序：

1. **会话列表的天气预报。** 每个会话行右侧一个小天气符号：在跑是雨、等你是雪、上次失败是雷暴，其余不显示。扫一眼侧栏就知道哪个会话需要你。`sessionWeather()` 已经给出映射，缺的是服务端在会话摘要里带上运行与等待状态。
2. **Project 的天气图。** Overview 里每个 Thread 的状态点换成天气：一个项目同时有几处在下雨、哪里在下雪等你，像看一张气象图。
3. **上下文即云量。** 顶栏的上下文圆环用云量表达：0–60% 晴，60–85% 多云，85% 以上起雾并提示压缩。
4. **权限即气候。** 只读是晴天，工作区可写是多云，完全访问是"雷暴预警"——一个提醒风险的视觉，而不是阻挡。
5. **审批即风暴预警。** 等审批的通知用雪花，自动审批拒绝用冰雹（hail），与普通错误的雷暴区分。
6. **问候语的天色。** 空会话的问候按当地时间换天色：清晨的薄雾、正午的晴空、傍晚的霞光、夜里的星。
7. **推理强度即气压。** 模型选择器里的 low / medium / high 用气压计表达"在里面想得多深"。
8. **长任务的天气日志。** Goal 模式跨多轮推进时，时间线顶部一条细细的"天气带"，按轮次记录晴、雨、雷暴——回看一次长任务的起伏。
9. **稀有的惊喜。** Goal 完成或长时间无错误运行后，偶尔出现一次蓝色喷流（blue jet）或极光，只在大头像上，只一次。

## 不做的事

- 不用天气表达"好坏评价"或分数。雷暴只表示需要看一眼，不表示 Agent 不好。
- 不把天气做成唯一的信息来源：每种天气都有文字标签（`WEATHER_LABEL`，也是头像的无障碍名称），颜色与动效之外总有文字。
- 不为了天气改变布局或抢占注意力；它只出现在 Agent 自己身上和它的状态位置。
