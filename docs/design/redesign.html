Tnega · dense redesign

docs/design/redesign.html · 2026-10-08 · draft for review

A whole-app change: same sky palette and weather language, but a tighter scale. Icons drop to 12–14px line glyphs with no tinted tiles, rows go from 34–36px to 24–26px, and chrome (workspace card, header, composer) gets thinner, so noticeably more fits on one screen without making the body text hard to read. Each pair below uses identical markup; only the token block changes (.t-old → .t-new).

Sidebar is organised by workspace. The workspace switcher card and the Sessions / Projects toggle are gone. Each workspace is a collapsible group: its projects (board icon) come first, then its sessions by recency, then "N older". Hovering a workspace row shows New project and New session; "Add workspace" sits in the footer. Window controls: the dashed box marks the native minimise / maximise / close overlay (138 × 32). --header-h becomes 32px, the same as TITLE_BAR_HEIGHT, so the controls sit inside whichever bar touches the top-right corner, which reserves 146px of padding on the right (.window-controls-header already does this).

Rules
  1. Every icon is a 1.5px stroke on a 16-unit grid, drawn at 14px (or 12px inline). No fills except the brand cloud and status dots.
  2. Icons are --text-3 at rest and --text on hover; color carries meaning only for status.
  3. Status is a 6px dot plus a label or tooltip. The weather avatar appears only on the active turn and in the header.
  4. No bordered card around a single tool row; groups get a 1px left rule instead.
  5. Secondary chrome (workspace card, search field, footer labels) goes transparent and only appears on hover.
  6. Hit targets stay ≥24px even when the glyph is 12px; the padding does the work.
  7. Optional data-density="comfortable" restores the old scale for anyone who wants it.
