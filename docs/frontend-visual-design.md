# Tnega Studio · 视觉设计规范

本轮以已完成 Astryx 迁移的 main 为基础。目标是一个安静、可长时间阅读的 Agent 工作台：导航退后，任务内容居中，执行状态可辨认。

## 色彩与材料

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 外壳 | `#eeefeb` | `#171b1a` | 导航、标题栏、辅助面板 |
| 工作面 | `#fafbf8` | `#202524` | 对话与项目内容 |
| 抬升面 | `#ffffff` | `#282e2c` | 输入、独立任务、表单 |
| 正文 | `#25312d` | `#e5eae6` | 标题、消息 |
| 次级文字 | `#627069` | `#a6b3ab` | 路径、说明、元数据 |
| 品牌强调 | `#267466` | `#91c7b8` | 主动作、选中、焦点 |
| 分隔线 | `#dce2db` | `#36403a` | 面板边界、表格 |

颜色只在 `apps/web/src/workbench/theme.ts` 定义。Astryx 原生组件与保留的 Tnega 专用视图共用这一套语义 token。深浅主题必须同步，不能只校准黑色截图。警告使用琥珀色，失败使用珊瑚红，颜色同时配合文字状态。

## 布局与层次

- 顶栏承载品牌与侧栏折叠；只有 Electron 预留系统窗口按钮空间。
- 左侧是可折叠的工作区与会话导航。新建、搜索、项目、工作区、设置形成固定顺序，设置落在底部。
- 主工作区使用略亮的工作面。正文与输入同一条对齐线，最大 800px，左右留 24px；长内容自然滚动。
- 对话标题独立于正文。消息正文 14px、1.75 行高，工具详情与元数据使用次级字号。
- 输入区是主要抬升面：16px 内距和圆角，轻描边。计划面板使用相同材料，避免超大胶囊与多层框线。
- 项目概览、记忆、线程和子代理延续相同材料与文本层级；数据保持行式结构。
- 小屏保留主要输入与消息区域，辅助栏按需打开。输入工具允许换行，不能靠缩小文字挤进一行。

## 组件与交互

组件优先使用 Astryx。用 Heading、Text、Stack 定义欢迎页层次；使用原有 Tree、Chat、Selector、Dialog 等交互。业务数据、模型选择、权限、Agent Run、持久化、审批和流式消费仍由原模块负责。

空白页提供清晰的下一步，不装饰虚假的统计数字。主动作使用强调色，次级动作使用 ghost。焦点必须可见，不能仅依赖 hover 暴露操作。动效遵循系统 reduced-motion。

## 视觉校准稿

运行 Web 开发服务，打开 `/design.html`。这是使用生产 Theme、WorkbenchShell、WorkspaceSidebar、MessageBlock 和 ComposerFrame 的可交互视觉稿，所有会话内容为本地样例，不调用模型或后端。可切换深浅主题、折叠导航、输入草稿与查看工具占位面板，用于校准真实组件而非一张脱离实现的图片。

## 验收

检查深浅主题、欢迎页、长文本和输入区。执行 Web typecheck/build，以及已有导航、输入、项目行为测试；不为颜色、圆角等实现细节增加测试。外壳工具页仍为原有占位功能，视觉稿不会把它们描述成已接入能力。

## Project 工作区

参考 [Claude Projects 官方说明](https://support.claude.com/en/articles/9517075-what-are-projects) 的共享上下文、Threads 和 Library 信息结构。Tnega 采用自己的协调者模型与 Studio 视觉，不复制未接入的上传、文件预览或第三方服务。

- 项目标题区：项目名、目标、连接状态、委派线程数量与 Overview / Library / Memory 切换。
- 主对话：唯一的用户消息入口。需求发给主 Agent，由它分发到子 Thread。
- 子 Thread：只读执行记录，显示目标、预期结果、状态、计划与流式正文。删除输入区、草稿状态和 Web 客户端发送函数；底部说明调度关系。
- Overview：项目目标摘要、线程/资料/记忆计数，以及按状态分组的任务行。统计只来自真实记录，主 Agent 不计入委派线程数。
- Library：分为 Agent 产物与参考资料，支持标题、来源和标识搜索；文件行展示类型、大小与引用。
- Memory：以知识条目而非密集卡片呈现，保留新增、编辑、删除、版本控制与历史。版本历史按条目关联。
- 宽屏并列主区与资料栏；1000px 以下资料栏移到主区下方，避免挤压对话。

项目视觉稿：开发服务 `/design.html?project`。直接使用生产 `ProjectExperience`，以仅在设计入口安装的本地模拟接口提供数据。Memory 修改只存在于当前预览内存，刷新复原；不会连接真实项目。通过侧栏 Appearance 可以检查两种主题。
