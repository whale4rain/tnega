# Tnega v0.4.19-beta.2

## Fixes

- **Scrollable Agent exchanges.** Long conversations scroll to every message;
  participant names are centered with more space after the text.
- **Reachable Workbench tabs.** Ordinary mouse-wheel movement scrolls the tab
  rail horizontally. Its scrollbar stays interactive on Windows, native window
  buttons retain their space, and Close workbench stays visible.
- **Plain ordinary Sessions.** User and Agent messages in ordinary Sessions have
  no bubble background. Projects keep their chat bubbles and compact typography.
- **One Project action.** An empty input shows Stop (disabled when idle); content
  switches it to Send. Enter sends asynchronously, Ctrl+Enter interrupts and
  sends a correction, and Esc stops the current Run.
- **No tool startup cursor feedback.** Windows desktop built-in restricted
  shell/search workers use the native utility launcher and suppress Windows
  startup feedback. Output, stdin EOF, exit codes and process cleanup are
  preserved; ordinary programs and custom sandbox runners keep their launch path.

## Other

- **Local implementation checks.** Browser E2E now covers long histories,
  crowded tabs and plain Session messages. New Electron E2E covers restricted
  workers, complete large output, stdin EOF and descendant cleanup. These E2E
  checks remain outside CI.

## Install

```bash
npm install -g tnega@0.4.19-beta.2
```

Windows: download **Tnega-Setup-0.4.19-beta.2.exe**, or select Preview in
Settings → Update channel and check for updates.

This preview updates 0.4.19-beta.1 and is published to npm's `preview` channel.
Session and Project storage formats are unchanged; no migration is required.
