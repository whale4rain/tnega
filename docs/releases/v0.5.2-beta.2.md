# Tnega v0.5.2-beta.2

## Features

- Glass can cover the whole app. Settings → Appearance → Glass has three choices:
  **Floating only** (the default, the shells that float over the app), **Everywhere**
  (the sidebar, the conversation header, the composer, the Workbench card and the
  dialogs take the same material), and **Off** (a solid app). Everywhere mode also
  paints a tinted backdrop behind the app, because glass over a flat colour is
  indistinguishable from a translucent tint; body text stays above its contrast
  floor over it.
- A long session opens on its newest page instead of its whole history, and
  **Load older messages** brings the previous page in above what you were reading
  without moving it. The session response no longer carries a second copy of the
  messages: on an 8,000-event session that turns a 4.5 MB reply into 46 kB, and the
  first paint after clicking the session went from 478 ms to 31 ms here.

## Fixes

- A run belongs to the session that started it. Switching away no longer leaves
  Stop armed, no longer shows "this session is running elsewhere" under an idle
  transcript, and no longer lets the run's stream land in the session you opened.
  Switching back reloads that session's history and keeps the run live.
- One-off confirmations (steering sent, CodeMode toggled, continuing an
  interrupted run) dismiss themselves instead of staying under the transcript.

## Install

```bash
npm install -g tnega@0.5.2-beta.2
```

Windows: download **Tnega-Setup-0.5.2-beta.2.exe** from this release, or select
the Preview update channel.
