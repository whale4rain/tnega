# Tnega v0.4.9

- **Offline skills.** Twelve bundled skills cover research, documents, planning, data processing, coding, debugging, review, TDD, DDD, Tnega usage and skill management. Startup installs missing files into `~/.tnega/skills` (or `TNEGA_HOME`) without overwriting user edits; Workspace overrides retain priority. General, coding and Project agents discover descriptions and load instructions as needed.
- **Skill management.** Add `skill_create` and `skill_install`, plus coding `/skills create`, `/skills install` and `/skills read`. Install a `SKILL.md` from a Workspace file/directory or an HTTPS raw Markdown link. Existing files are preserved; write and network permissions remain enforced. Companion assets are not imported and downloaded content is not executed.
- **Settings.** A wider responsive dialog separates model connection and approvals into two columns, collapsing to one on smaller screens and keeping save actions visible.
- **Desktop completion.** Sessions play one system sound at completion. An unfocused Windows client shows a rain taskbar badge for a ready reply or lightning for a failed run; returning to the window clears the badge. Cancellation and intermediate Goal rounds do not notify. Reply avatars keep their existing appearance.

## Install

```bash
npm install -g tnega@0.4.9
```

Windows: download **Tnega-Setup-0.4.9.exe** from this release, or let an installed client update itself (Settings → Check for updates).

This is a stable release. Use Settings → Update channel → Stable and Check for updates. After clicking Update, wait for installation and automatic restart before opening a shortcut again.

When upgrading from a client before 0.4.7, close old desktop/CLI processes before first use. Legacy Workspace histories are imported into user home with backups retained and conflicts reported; Project configuration, memory, skills and artifacts stay in the Workspace. Session formats are unchanged.

## Validation

- Root and desktop TypeScript checks and lint pass. All 12 standalone npm package artifact checks pass, including offline installation of the bundled skills from copied build output.
- All 33 desktop tests and 6 browser provider tests pass in a serial verification run. Agent tests pass on targeted retry; taskbar notification tests cover completion, failure, cancellation, duplicate terminal events and clearing on focus.
- The initial full-suite run recorded 1252 passed, 20 failed and 18 skipped, plus a package-build timeout. Its 17 persistent failed test names match the 0.4.8 baseline. Additional Agent cleanup, Electron/browser timeout and package-build failures pass on isolated retries after concurrent builds finish. The full suite is not claimed green; existing mode, slash-command, Session, HTTP fixture and SSE assertions remain test debt.
