# Tnega v0.4.23

## Features

- Project 主对话改为任务驱动：用户消息保留靠右气泡，协调者回复铺满对话列；房间、Thread、Board 与欢迎页不再显示 Agent 头像。
- 协调者派出的 Thread 显示为带状态灯的链接卡，正文里的 Thread 链接可在工作台打开；Thread 工具栏新增「Messages with Coordinator」查看双方往来。
- Thread 和侧栏项目显示状态灯：等待或阻塞为琥珀色，失败为红色，工作中为缓慢明灭的强调色。项目列表 API 新增兼容旧客户端的 Thread 状态摘要。
- Thread 推送分支或创建 PR 后，在主对话、产物区和 Library 显示 Git 状态卡，可打开 PR 或创建 PR 的页面；再次推送同一分支会更新同一张卡。

## Fixes

- Thread 对话与 Agent 通信使用主对话底色，深色主题下不再呈现浅色文档卡片。
- 桌面侧栏、会话顶栏与工作台标签对齐原生标题栏按钮；拥挤的标签栏隐藏 Windows 横向滚动条，仍支持滚轮、触控板与选中标签自动滚入视野。
- Project 与 Thread 在空闲、输入为空时显示禁用的发送按钮，只有运行期间才显示停止按钮。

## Install

```bash
npm install -g tnega@0.4.23
```

Windows: download **Tnega-Setup-0.4.23.exe** from this release, or let an installed client update itself (Settings → Check for updates).

Existing model configurations, Projects and Sessions need no migration.
