# Tnega v0.5.2-beta.6

## Features

- Sending while a run goes queues the message in both the web app and the TUI
  instead of dropping it. A queued message can be steered into the running turn
  (**Steer now** or Ctrl+Enter in the web app, Tab or Alt+Enter in the TUI),
  edited back into the composer or removed; a run that ends on its own sends the
  queue as the next prompt.
- The sidebar searches what was said, not just titles. From two characters a
  query also finds sessions by their messages and shows the matching line
  beside them, while titles filter from the first character. Opening the
  sidebar, or coming back to the window, refreshes every list, so a session
  started in the terminal or another window appears without waiting for the next
  poll.
- **Select** in the sidebar turns the session lights into checkboxes: pick
  several sessions (Shift extends a range, and one batch can span folders) and
  delete them through a single confirmation.
- **New project** sits at the top of the sidebar, and its dialog can place the
  project in any listed folder.

## Fixes

- A queued message stays queued when the turn itself failed: the run's stream
  can end normally after an error, which used to send the queue as the next
  prompt. Stopped and failed runs now both leave the queue waiting.
- Glass everywhere reads as glass and stays readable: dialogs no longer take
  glass over the frosted scrim, so light dialogs stay light and tertiary text
  clears 4.5:1; the Workbench frame and its conversation-like panels let the
  backdrop through; the desktop title bar resyncs when the Glass setting
  changes; and the composer is no longer its own band under a rule — the
  transcript fades out behind the composer card, as in the default theme.

## Install

```bash
npm install -g tnega@0.5.2-beta.6
```

Windows: download **Tnega-Setup-0.5.2-beta.6.exe** from this release, or select
the Preview update channel.
