# Tnega v0.4.5

- Projects bring coordinator conversations, parallel Threads, shared Memory and a Library of files and artifacts into the local interface.
- Work agents create, inspect and edit Word documents, Excel workbooks and PowerPoint presentations. Generated Office files appear as preview cards with zoom and download controls.
- The desktop app uses the new teal icon. Native window buttons share the existing header, with horizontal clearance and draggable empty space.
- Minimizing the desktop window hides it in the notification area. Click the tray icon or use Show Tnega to restore it; Exit Tnega shuts down the runtime.
- Sandboxed preloads are built as CommonJS so native integration loads correctly.
- Session writers retain live ownership when temporary readers close, preventing false interruption results in that lifecycle sequence.

## Install

```bash
npm install -g tnega@0.4.5
```

Windows: download **Tnega Setup 0.4.5.exe** from this release and close the previous client before installing.

Requires Node.js >= 22.19.0 for the CLI. Session format remains v10; older formats are rejected rather than migrated in place.
