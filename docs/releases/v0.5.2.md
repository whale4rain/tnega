# Tnega v0.5.2

This stable release gathers everything since 0.5.1, including the seven 0.5.2
previews.

## Features

- **Turns run until they stall, not until a step count.** A loop guard watches
  for repeated calls, cycles, repeated errors and steps without progress. A turn
  that keeps moving may run long; one that stalls is nudged, then asked to
  reflect, then parked so the model reports what it finished and what it needs.
  A soft limit parks, rather than kills, a turn that reaches 4M tokens or two
  hours.
- **Context tab and Context insights.** The workbench shows what the current
  session's context is made of, request by request, against the model's window.
  Settings → Context insights replaces Usage with totals, a twelve-week
  heatmap, timing and searchable session cards.
- **Dreaming.** Sessions that changed and went quiet are read in the background
  and folded into the workspace's project memory. Settings → Model → Dreaming
  turns it off, picks the model and sets the quiet time.
- **MXC sandbox on Windows.** The Windows sandbox tries a Microsoft eXecution
  Container first and falls back to the ACL runner. On Windows 11 24H2 and
  later without an executor, a notice suggests installing it;
  `TNEGA_MXC_EXEC=off` forces the ACL runner.
- **Queue and steer.** Sending while a run goes queues the message in the web
  app and the TUI. Steer it into the running turn, edit it back or remove it; a
  run that ends on its own sends the queue next.
- **A sidebar that finds and tidies.** Search matches what was said, not only
  titles, and shows the matching line. **Select** deletes several sessions at
  once, every session row has a status light, and **New project** sits at the
  top with a folder picker.
- **Glass.** Menus and popovers are glass over a blurred backdrop, and
  Settings → Appearance → Glass can cover the whole app (**Floating only**,
  **Everywhere** or **Off**). Reduced transparency makes them opaque again.
- **Long sessions open fast.** A session opens on its newest page and loads
  older messages as you reach the top, keeping your place. An 8,000-event
  session went from a 4.5 MB reply to 46 kB.
- **Mermaid diagrams** draw from code fences in the app's own colours, with the
  source one toggle away.
- **Files open where they belong.** Clicking a workspace file opens it by type:
  HTML as a page in the workbench browser (its relative assets load), Markdown
  rendered in Files with a **Preview**/**Source** switch, office files and
  images in a preview tab. Right-click a file link, changed file, office card
  or tree row for **Edit in Files**, **Copy path** and, on the desktop,
  **Open with default app** and **Show in folder**.
- Project threads and the coordinator answer in the language you wrote in, and
  a thread's report reaches the coordinator in full.
- The conversation stops following new output while you scroll back to read.

## Fixes

- A run stays in the session that started it: switching sessions no longer
  shows its reply, approval card or Stop button in another one, and switching
  back keeps it live.
- A new session is named after its first turn that finished cleanly, even when
  an earlier turn was stopped or failed. A manual rename still wins.
- A message box keeps its draft only for the conversation it was typed in.
- A queued message stays queued when the turn failed or was stopped.
- The workbench Browser tab gets live tab and page updates again, stays
  responsive on pages that repaint all the time, and on the desktop follows the
  panel while it slides.
- The sidebar and workbench keep their state when folded, and the title-bar
  actions stay still while they fold.
- The desktop window controls take the colour of the bar they sit in, and Glass
  everywhere no longer paints a glow at the window edges.

## Other

- New packages: `@tnega/loop-guard` (published as `tnega/loop-guard`),
  `@tnega/context-insights`, `@tnega/memory-dream` and
  `@tnega/sandbox-windows-mxc`. `@tnega/agent` gains the `agent/step-limits`
  and `agent/step-end` mount points and an `agentId` on its events; existing
  listeners keep working.
- `pnpm release:tag` pulls main, checks the changelog and release notes for
  the current version, and pushes the tag.

## Install

```bash
npm install -g tnega@0.5.2
```

Desktop: download **Tnega-Setup-0.5.2.exe** (Windows), **Tnega-0.5.2-arm64.dmg** / **Tnega-0.5.2-x64.dmg** (macOS, Apple silicon / Intel) or **Tnega-0.5.2-x86_64.AppImage** / **Tnega-0.5.2-amd64.deb** (Linux) from this release. Installed Windows and Linux clients update themselves (Settings → Check for updates); macOS builds are unsigned, so they point to the new download instead.
