# Tnega v0.5.2-beta.1

## Features

- Menu, the `/` panel, the context popover and the reaction menu are glass: the
  raised surface at 0.8 over a blurred backdrop, so what is behind them reads as
  depth. The dialog scrim blurs what it covers the same way.
- The sidebar's session list fades out at its bottom edge instead of ending on a
  hard line.
- The conversation no longer pulls itself down while you read. It follows new
  output within 40px of the end and stops for 150 ms after you scroll, so a wheel
  tick upward is not yanked back by the next streamed token.

## Other

- Body text on a glass surface still clears its 7:1 floor against every surface
  the app itself draws behind a popover; over a photo, the browser view or
  another window it can drop to about 6.5:1. Turning on the system's reduced
  transparency setting makes floating layers opaque again.

## Install

```bash
npm install -g tnega@0.5.2-beta.1
```

Windows: download **Tnega-Setup-0.5.2-beta.1.exe** from this release, or select
the Preview update channel.
