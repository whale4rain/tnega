# Tnega v0.4.17

## Fixes

- **ChatGPT requests follow network settings.** OAuth token exchange, token refresh and Responses model requests use the configured proxy, environment proxy or desktop network transport.
- **Proxy POST requests retain their data.** The request method, body and authentication headers are preserved when forwarding through a proxy.

Configure the proxy in Settings → Tools & shell → Network. The local OAuth callback still uses localhost. OpenAI regional restrictions remain visible if the selected network route is unsupported.

## Install

```bash
npm install -g tnega@0.4.17
```

Windows: download **Tnega-Setup-0.4.17.exe** from this release, or let an installed client update itself (Settings → Check for updates).

This is a stable release. Session and configuration formats remain compatible; no migration is required.
