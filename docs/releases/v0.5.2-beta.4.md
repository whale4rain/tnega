# Tnega v0.5.2-beta.4

## Fixes

- The Workbench's live browser view stays responsive on pages that repaint all
  the time (carousels, ads — Baidu was the report). Screencast frames are capped
  at 15 fps and delivered at 1280x800 JPEG q60, and each frame is written
  straight into the page image, so the tabs and toolbar no longer re-render or
  stall while the page animates.

## Install

```bash
npm install -g tnega@0.5.2-beta.4
```

Windows: download **Tnega-Setup-0.5.2-beta.4.exe** from this release, or select
the Preview update channel.
