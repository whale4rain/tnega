# Tnega v0.4.10

- **System shell.** The `shell` and `process_start` tools run commands in your system shell — PowerShell 7, then Windows PowerShell, Git Bash or cmd on Windows; `$SHELL` elsewhere — and tell the model which syntax to write. Choose another one in Settings → Tools & shell (saved as `shell` in `config.json`, or set `TNEGA_SHELL`). Sandboxed Windows commands no longer pop up a console window. PowerShell output is plain UTF-8 text, and non-UTF-8 output is decoded with the system code page. Git Bash cannot run inside the Windows sandbox and is rejected with a reason; use it only with full access.
- **Fork from a reply.** Every finished reply has a visible **Fork from here** action that continues in a new session from that point. Forks keep the agent type, mode, model and title; the header menu's whole-session fork is now "Fork entire session".
- **Quieter tool failures.** Errors the agent handles itself (a 404, a missing file, invalid input) no longer show as red failures. They fold into the completed process and read "Returned to the agent"; only failures that need you (sandbox, permissions, missing tool or credentials) stay flagged. The model still receives every error unchanged.
- **Steadier tool streaming.** Tool calls stream as a flat list while a turn runs instead of a folder opening and closing around each call, and fold once when the turn finishes.
- **Question notice.** When the agent asks a question or needs an approval, the desktop client sounds once, flashes the taskbar and shows a snow badge until you return to the window.
- **Settings sections.** Settings has a side navigation with Model, Approvals, Tools & shell, Appearance and About & updates, so new options have room. A failed save opens the section that needs fixing.
- **App dialogs.** Deleting a session or project, forgetting memory, discarding unsaved edits and error notices use Tnega's own dialog instead of the browser's native boxes.
- **Files without the tree.** Workbench Files can hide its file tree to give the editor the full width; the choice is remembered.

## Install

```bash
npm install -g tnega@0.4.10
```

Windows: download **Tnega-Setup-0.4.10.exe** from this release, or let an installed client update itself (Settings → Check for updates).

This is a stable release. Use Settings → Update channel → Stable and Check for updates. After clicking Update, wait for installation and automatic restart before opening a shortcut again.

Session and config formats are unchanged; `shell` is a new optional config field. Commands that relied on cmd.exe syntax now run in PowerShell by default on Windows; set the shell to cmd in Settings to keep the old behaviour.
