# Tnega v0.4.8

- **Browser theme.** Opening Browser no longer changes the desktop's system theme. CDP attachment preserves the host's media preferences; new tabs and reconnection retain System, Light and Dark selections.
- **Windows sandbox.** Fix `windows-acl runner entry not found ... app.asar/out` in installed clients. The desktop ships the runner beside its main bundle and retains native koffi dependencies. Capability probes and execution use Electron's Node mode only for the runner; restricted commands retain their normal environment. Sandbox failures still refuse execution.
- **Release runbook.** npm publication is entered by the user in their own terminal. Document registry propagation delays, complete-asset verification, duplicate release recovery and temporary Windows shortcut/icon warnings while installing updates.

## Install

```bash
npm install -g tnega@0.4.8
```

Windows: download **Tnega-Setup-0.4.8.exe** from this release, or let an installed client update itself (Settings → Check for updates).

This is a stable release. Select Stable in Settings → Update channel and use Check for updates. After clicking Update, wait for installation and automatic restart before opening a shortcut again.

## Validation

- Root and desktop TypeScript checks and lint pass. Browser theme regression reproduces the original dark-to-light change in a hidden Electron host and passes after the fix across attachment, new tabs, reconnect and all theme preferences.
