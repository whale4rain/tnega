# Tnega v0.4.19

## Features

- **Compact Agent chats.** Open Messaged receipts as conversations between two
  Agents in the Workbench, follow restored history, and open referenced files or
  websites. Coordinators and Threads are guided to send short messages.
- **Get models from your connection.** Fetch live models with ChatGPT sign-in,
  OpenAI-compatible or Anthropic credentials. Reuse saved connections and legacy
  top-level API configurations without exposing keys to the browser.
- **Add from the model picker.** Session and Project selectors separate model
  providers and third-party models. Search, add and select a model directly,
  retaining the draft and reasoning settings. Manual entry remains available.

## Fixes

- **Tighter typography.** Shared smaller type and spacing throughout the app;
  ordinary Sessions have plain messages, and Projects keep chat bubbles.
- **Reachable conversations and tabs.** Long Agent exchanges and crowded tab
  rails scroll, participant names are centered, and native Windows controls keep
  their space.
- **One Project action.** Empty input shows Stop; content switches to Send.
  Ctrl+Enter interrupts and sends, and Esc stops the current Run.
- **Windows tool launches.** Restricted workers suppress startup cursor feedback
  while preserving output, stdin EOF, exit status and descendant cleanup.
- **Consistent model connections.** Discovery and saved models use the same
  endpoint and authentication header. Cancelled saves refresh persisted models
  without unexpectedly switching the active model.

## Other

- **Local E2E.** Browser and Electron checks cover incremental chat, model and
  worker behavior; these checks remain outside CI.
- **Validation scope.** At the maintainer's request, this release does not rerun
  the full suite. Targeted tests and local E2E passed; build and artifact checks
  remain in the release workflow. Later releases retain the full-suite gate.

## Install

```bash
npm install -g tnega@0.4.19
```

Windows: download **Tnega-Setup-0.4.19.exe** from this release, or let an installed client update itself (Settings → Check for updates).

This stable batch includes the changes since 0.4.18, including both 0.4.19
previews. npm publishes it to `latest`; desktop clients use `latest.yml`.
Existing Sessions, Projects and model configurations need no migration.
