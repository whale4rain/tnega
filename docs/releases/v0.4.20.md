# Tnega v0.4.20

## Fixes

- ChatGPT login requests omit inherited temperature, including when no reasoning
  effort is configured. This fixes HTTP 400 `Unsupported parameter: temperature`.
  API-key model sampling settings continue to work.

## Other

- Validation is limited to the related ChatGPT and Responses regression tests,
  a live request, type checks, lint, build and artifact integrity checks, as
  requested by the maintainer. The full suite is not rerun for this hotfix.

## Install

```bash
npm install -g tnega@0.4.20
```

Windows: download **Tnega-Setup-0.4.20.exe** from this release, or let an installed client update itself (Settings → Check for updates).

Existing model configurations and Sessions need no migration.
