# Tnega v0.5.5

This release follows 0.5.4 with a sharper web surface: `web_search` now talks to
DeepSeek's own Search API and reports what it found, a new `web_fetch` reads a
page as Markdown, DeepSeek V4 finally offers its effort levels, and two web
client nits are gone.

## Features

- **`web_search` uses DeepSeek's Search API.** It calls `POST /v1/tools/search`
  with the same DeepSeek key instead of wrapping a hidden model call, and
  returns `{ results: [{ title, url, summary, site, publishedAt }] }`, best
  first, with each URL listed once. The query (at most 128 characters) takes the
  API's own operators — `site:`, `-site:`, `"exact phrase"`, `-term`,
  `lang:zh,en`, `after:2026-01-01`, `before:2026` — and two optional arguments:
  `question`, the user's own wording, sent as `ori_question` to sharpen the
  search, and `count`, 1–20 results (default 8).
- **`web_fetch` reads a page as Markdown.** `web_fetch({url})` returns
  `{ url, title, content, truncated }` for one public page, cut at 60 000
  characters, so a search hit can be read in full; `http_get` stays for APIs,
  raw files and headers. Both tools declare themselves read-only, run alongside
  other read-only calls in the same message, and need no approval. Without a
  key they say to set `DEEPSEEK_API_KEY`.
- **DeepSeek V4 offers its effort levels.** A DeepSeek route now lists Low and
  High effort instead of none, and a saved model route that lists no
  `reasoningEfforts` takes them from its model id rather than from an empty
  list, so the effort dropdown appears for the model you added.

## Fixes

- A `web_search` request that succeeds without a JSON body is a provider failure
  with a stated reason, not an empty result list.
- The queued-messages card keeps **Steer now**, edit and remove in view when a
  message is longer than the card; only its text is truncated.
- Opening the process of a turn whose process is one run no longer folds it
  twice: its thoughts are listed one by one and the tool calls between two
  thoughts collapse into one line ("Read 2 files, ran a command").

## Other

- Design notes and `AGENTS.md` describe the web domain's two model-visible tools
  and the narrower process fold. `@tnega/tool-web-search` now depends on
  `@tnega/core` for its plugin shape.

## Install

```bash
npm install -g tnega@0.5.5
```

Desktop: download **Tnega-Setup-0.5.5.exe** (Windows), **Tnega-0.5.5-arm64.dmg** / **Tnega-0.5.5-x64.dmg** (macOS, Apple silicon / Intel) or **Tnega-0.5.5-x86_64.AppImage** / **Tnega-0.5.5-amd64.deb** (Linux) from this release. Installed Windows and Linux clients update themselves (Settings → Check for updates); macOS builds are unsigned, so they point to the new download instead.
