# Tnega v0.5.8-beta.2

The second preview of 0.5.8 closes the remaining box gaps — subagents, MCP
servers over `--pipes`, egress proxy key placeholders with live refresh, and
E2B Workbench support — fixes resident coding MCP startup, and ships a round of
Umbrella UI and macOS desktop polish.

## Features

- **Subagents in boxes.** Runs in a box now get `spawn_subagent` and the other
  subagent tools. Subagents share the parent scope's tools so their commands
  and files run inside the box while their Sessions stay in host state, and the
  box lease stays held until all running subagents settle.
- **MCP servers in boxes.** `tnega daemon --pipes` (enabled by the box start
  script) serves long-lived stdin/stdout processes inside the box, with a
  30-second cleanup timer for unattached processes. Coding sessions in a box
  read the box's own `.tnega/mcp.json`, run MCP servers there with egress proxy
  placeholders and bounded, prefixed stderr logging, and omit host-disk skill
  tools. Older box images without `--pipes` continue to run without MCP.
- **Egress proxy key placeholders and live refresh.** Box commands, Project
  thread boxes and box MCP servers now receive `tnega-egress-adds-NAME`
  placeholders for keys the egress proxy actually adds. Saving or removing a
  remembered secret refreshes every live box's policy immediately instead of
  waiting for the next resume, serialized so a slow refresh never writes back a
  removed key.
- **E2B Workbench.** On servers whose boxes keep their own volume, the
  Workbench file tree, editor, uploads, Changes (with byte-exact `git show`)
  and `@` file search work against the signed-in person's running box without
  waking sleeping boxes (`503` while asleep, `413` above the 16 MiB daemon
  message limit).
- **Umbrella layout, elevation and brand polish.** Gave session screens more
  room and fewer heavy ink surfaces, added a soft elevation scale, sized
  controls to their text one step up the type ramp, and refined the sliced
  cloud mark to a single cut across Web, favicon and desktop icons.

## Fixes

- Fixed resident coding sessions never mounting the coding plugin (which
  previously waited on a `session` service absent from resident roots), so MCP
  servers now start reliably on both host and boxes. Broken `.tnega/mcp.json`
  configs or failing servers degrade to failed `/mcp` surveys without blocking
  the session or closing healthy servers, and disposal awaits MCP teardown.
- Smoothed Web reply streaming to render at an even pace without flashing
  half-written Markdown, and gave the Workbench toggle a clear panel icon and
  label.
- Kept the Umbrella floating shell and 44px brand row intact on macOS desktop
  builds, and fell back to the GitHub feed when `app-update.yml` is absent.

## Other

- Refreshed `README.md`, `docs/zh-CN.md`, Umbrella specs
  (`docs/design/umbrella/session-inventory.md` and related docs), screenshots,
  `docs/guide/server.md` and daemon documentation.
- **Box upgrade note:** rebuild the E2B template (`pnpm try:boxes template`) or
  gVisor rootfs (`deploy/gvisor/build-rootfs.sh`) to enable MCP servers in
  boxes; older images continue to work without MCP until rebuilt.
- GitHub Actions remains paused to manual runs. Pushing this tag does not start
  a release automatically; a manual run of **Release** for `v0.5.8-beta.2`
  publishes npm under `preview` and desktop preview clients from `beta.yml`.

## Install

```bash
npm install -g tnega@0.5.8-beta.2
```

Desktop: download **Tnega-Setup-0.5.8-beta.2.exe** (Windows),
**Tnega-0.5.8-beta.2-arm64.dmg** / **Tnega-0.5.8-beta.2-x64.dmg** (macOS, Apple
silicon / Intel) or **Tnega-0.5.8-beta.2-x86_64.AppImage** /
**Tnega-0.5.8-beta.2-amd64.deb** (Linux) from this release. Installed Windows
and Linux clients update themselves (Settings → Check for updates); macOS builds
are unsigned, so they point to the new download instead.

This is a prerelease: select **Preview** under Settings → Update channel to
receive it, and note that a preview install does not downgrade when you switch
back to Stable.
