# Tnega v0.4.22

## Features

- **Colour palettes.** Settings → Appearance adds Sand (warm paper with a
  terracotta accent), Forest (green-grey with deep teal) and Graphite (neutral
  grey, highest contrast) beside the default Sky, each in light and dark and
  held to the same contrast floor. The cloud mark follows the palette's accent;
  weather status colours stay the same.
- **Display options.** Choose density (Compact / Comfortable), text size
  (Small / Default / Large) and conversation width (Narrow / Standard / Wide /
  Full width). Changes apply instantly, are remembered per device and are
  applied before the first frame, so pages don't flash.

## Fixes

- **Faster automatic approval on DeepSeek.** LLM approval reviews on DeepSeek's
  API no longer generate hidden reasoning. Each Project Thread shell call waited
  for that review; the median review time fell from about 1.8 s to about 1.0 s,
  and the roughly one-in-ten reviews that ran out of budget after about 20 s
  and escalated to the coordinator no longer happen. Other model routes are
  unchanged.

## Other

- **New README.** The README now introduces what Tnega is, why to use it and
  how to start; detailed reference moved to the new
  [usage guide](https://github.com/whale4rain/tnega/blob/main/docs/guide/README.md).

## Install

```bash
npm install -g tnega@0.4.22
```

Windows: download **Tnega-Setup-0.4.22.exe** from this release, or let an installed client update itself (Settings → Check for updates).

Existing model configurations, Projects and Sessions need no migration.
