# Tnega v0.5.8-beta.1

The first preview of 0.5.8 introduces the Umbrella design language and Swiss
geometric sliced cloud mark across the Web and desktop UI, `/btw` temporary side
chats, isolated per-thread boxes and server-scheduled routines for Projects, and
`tnega boxd` with a Server admin panel in Settings.

## Features

- **Umbrella design language and sliced cloud brand mark.** Rebuilt the Web and
  desktop UI with tonal surfaces without outer borders or shadows, hand-drawn
  `PenMark` cues for status, plans and asks, a redesigned Sidebar, Conversation,
  Projects Board, Workbench and Settings, and a warmer new-session welcome with
  greeting, recent sessions and starter chips. Replaced the brand mark, main
  Agent avatar, favicon and desktop app icon with the Swiss geometric sliced
  cloud.
- **`/btw` and temporary side chat.** `/btw` asks a quick question about the
  current session without saving it to the log or interrupting the running
  Agent. The sidebar's Temporary chat opens the same throwaway chat in a
  Workbench tab, and the TUI displays `/btw` answers above the composer.
- **Server Projects with per-thread boxes, schedules and lifecycle.** Project
  thread logs live in the server's session store (`ctx.sessionStore`), and
  `ctx.effects` runs Project routines on a Postgres schedule even with no window
  open. Each Project thread runs in its own isolated box with its own repo
  clone, branch and pull request card, with unattended turn limits. Remembered
  `GITHUB_TOKEN` keys are injected for GitHub hosts by the egress proxy and
  threads open/check PRs via GitHub's REST API rather than the host `gh` login.
  Idle projects unmount automatically, reconcile on server startup, and clean up
  thread clones and pushed branches when deleted.
- **`tnega boxd` and Settings → Server admin page.** `tnega boxd` runs as the
  sole root process on a gVisor host over a Unix socket (`TNEGA_BOXD_SOCKET`),
  removing direct host commands from the server process. Added Settings → Server
  (with Account promoted to the top section) so owners and admins can manage
  people, devices (marking connected daemons) and boxes (with pause/stop).

## Fixes

- Hardened `boxd` folder pinning and mounting: opens host folders once and
  bind-mounts pins via `/proc/<pid>/fd` under a private pin root so `runsc` can
  mount them without symlink-swap races, reuses an already-running box's pin on
  repeated starts, enforces root and ownership checks, locks down the socket
  directory, and removes pins safely with `rmdir` after unmount.
- Refined Umbrella UI and desktop chrome details: kept symmetrical bottom panel
  gaps on Project and welcome views, prevented Settings dialog re-renders from
  stealing focus or falsely marking self-saving model forms dirty, surfaced
  full-text search snippets in `Your turn`, prevented count badges from
  overflowing round Workbench tabs, and aligned desktop window chrome headers.

## Other

- Added the Umbrella component specifications under `docs/design/umbrella/` and
  updated `docs/design/tnega-design.md`, `docs/design/weather-language.md` and
  `docs/guide/server.md`.
- GitHub Actions remains paused to manual runs. Pushing this tag does not start
  a release automatically; a manual run of **Release** for `v0.5.8-beta.1`
  publishes npm under `preview` and desktop preview clients from `beta.yml`.

## Install

```bash
npm install -g tnega@0.5.8-beta.1
```

Desktop: download **Tnega-Setup-0.5.8-beta.1.exe** (Windows),
**Tnega-0.5.8-beta.1-arm64.dmg** / **Tnega-0.5.8-beta.1-x64.dmg** (macOS, Apple
silicon / Intel) or **Tnega-0.5.8-beta.1-x86_64.AppImage** /
**Tnega-0.5.8-beta.1-amd64.deb** (Linux) from this release. Installed Windows
and Linux clients update themselves (Settings → Check for updates); macOS builds
are unsigned, so they point to the new download instead.

This is a prerelease: select **Preview** under Settings → Update channel to
receive it, and note that a preview install does not downgrade when you switch
back to Stable.
