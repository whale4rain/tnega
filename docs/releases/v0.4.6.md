# Tnega v0.4.6

- **Workbench.** One right-hand panel holds Files, Changes, Terminal and Browser, plus closable tabs for document previews and subagent transcripts. The conversation header has a single Workbench button with a changed-files badge; Ctrl+J toggles it and Ctrl+` opens the terminal.
- **Terminal.** Your own shell in the workspace on a real PTY. Several sessions run side by side and survive switching tabs.
- **Changes.** Git changes in the workspace with a unified or side-by-side diff, refreshed as the agent edits. Files in a turn's "files changed" card open their diff.
- **Files.** A workspace tree beside a code editor with syntax highlighting. Ctrl+S saves, and a save never overwrites a newer change on disk. Previews now cover images and PDFs as well as Word, Excel and PowerPoint.
- **Agent browser.** The agent's browser runs inside the app in both the desktop and web clients, with tabs, a resizable panel and an element picker that drops a page element into your message.
- **Images.** Attach, paste or drop images into the composer. Models that cannot read images get a text fallback.
- **Background work.** Long-running commands such as dev servers run in the background; background tasks show in the header with stop controls.
- **Plugins.** External plugins can load from profile files (`~/.tnega/profiles/default.yaml`) and hot-reload in `tnega web` and the desktop app without a restart.
- **Projects.** Threads report and ask for decisions more reliably: a thread that needs an answer now waits for one instead of being marked done.
- **Design.** A sky palette with a measured dark mode, weather as the agent's state language, a new app icon and a calmer conversation header.
- **Self-update.** From this release on, the desktop app updates itself from GitHub releases. Update appears next to Settings when a new version is ready, and Settings has Check for updates.
- Eval, evolve and benchmark packages are removed.

## Install

```bash
npm install -g tnega@0.4.6
```

Windows: download **Tnega Setup 0.4.6.exe** from this release and close the previous client before installing. This is the first version that updates itself; later versions install from inside the app.

Requires Node.js >= 22.19.0 for the CLI. Session format remains v10; older formats are rejected rather than migrated in place.
