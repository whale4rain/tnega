# Tnega v0.4.25-beta.3

## Features

- A calmer sidebar: each row is a dot and a title, with details in the tooltip. Projects are pinned at the top, and workspace groups are ordered by their latest session.
- New sessions start in a scratch folder (`~/.tnega/scratch`, shown as "No folder") instead of requiring a workspace.
- On the desktop, the Workbench tabs sit in a row under the window controls and use the panel's full width.
- A livelier Project Board: a progress strip coloured by thread status, per-step checklist segments, outputs and pull requests that open from the card, and a "Recently" list.
- Sessions and Project threads cut off by a crash or restart pick up where they stopped. Tool calls that may already have taken effect are named, and the agent checks them before repeating anything.
- Only one process writes a session at a time; a second one gets a clear error.
- An interrupted `shell` command reports the output it had printed so far.
- Sending a message is safe to retry; a repeat after a dropped connection is queued once.
- The model's thinking shows as a muted "Thought" row that folds away when the answer starts.

## Fixes

- Reopening a crashed session repairs only the torn tail instead of rewriting the whole log, and keeps a copy of a log damaged in the middle.
- Stop ends a running tool call promptly, including MCP calls that never answer.
- DeepSeek in thinking mode no longer rejects tool loops with a 400 error.
- On Windows desktop, a sandboxed command no longer hangs the first time it runs in a workspace, and a folder the sandbox may not change fails with the reason and the fix instead of `Win32 5`.
- On Windows, Stop no longer waits for the sandbox's first-time permission setup.

## Other

- Sessions now store the model's reasoning. A session written by this version can't be opened by an older build.
- Stop interrupting tools and the Windows sandbox fixes have not yet been exercised on Windows beyond the release workflow's Windows test run.

## Install

```bash
npm install -g tnega@0.4.25-beta.3
```

Windows: download **Tnega-Setup-0.4.25-beta.3.exe** from this release, or select the Preview update channel.
