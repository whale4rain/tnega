# Tnega v0.4.24-beta.1

## Features

- Asynchronous Project memory extraction with configurable delayed-model routing, shared daily call/token limits and unverified candidates with sources.
- Isolated Git worktrees and one pull request per Thread; undelivered changes remain blocked.
- Artifact dialogs show the generating Thread beside the preview and support selected-text follow-ups. One Thread can manage multiple artifacts with stable identities and retained revisions.
- Coordinator messages display in full; Agent communication defaults to concise updates.

## Fixes

- Preserve the original request temperature in memory provider requests.
- Handle concurrent artifact publication and republishing older content without confusing newer revisions.

## Other

- Existing Sessions and artifacts remain readable. Worktrees are retained on shutdown; PR delivery requires origin access and GitHub CLI authentication.
- Prepared without further local tests or validation at the maintainer's request. CI configuration is unchanged.
- This requested preview sorts below stable 0.4.24; stable clients will not automatically downgrade to it.

## Install

```bash
npm install -g tnega@0.4.24-beta.1
```

Windows: download **Tnega-Setup-0.4.24-beta.1.exe** from this prerelease when assets are published.
