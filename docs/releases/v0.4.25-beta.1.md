# Tnega v0.4.25-beta.1

## Features

- Asynchronous Project memory extraction with configurable delayed-model routing, shared daily limits and source-bound unverified candidates.
- Separate Git worktrees and one pull request per Thread, with blocked status for undelivered changes.
- Artifact previews alongside their generating Thread, selected-text follow-ups and stable revision history. One Thread may manage multiple artifacts.
- Full Coordinator messages and concise Agent communication.

## Fixes

- Recognize existing Windows worktrees across short-path aliases and casing differences, avoiding duplicate checkout creation.
- Flush pending Session events before the memory test captures its unchanged-source baseline.
- Preserve the original temperature in memory side requests and correctly handle concurrent publication or republication of older artifact content.

## Other

- Corrects the preview target from 0.4.24 to 0.4.25 and includes the complete Project collaboration upgrade.
- No additional local tests were run at the maintainer's request. CI configuration is unchanged.

## Install

```bash
npm install -g tnega@0.4.25-beta.1
```

Windows: download **Tnega-Setup-0.4.25-beta.1.exe** when the prerelease assets are published, or select the Preview update channel.
