# Tnega v0.4.16

## Fixes

- **ChatGPT sign-in starts correctly.** The login request now sends its required JSON body, fixing the HTTP 415 error before OAuth starts. Cross-site request checks remain enabled.
- **Workspace instructions fit their panel.** The editor and help text use a full-width stacked layout with theme-aware styling.
- **Usage fits without horizontal dragging.** The calendar adapts to the panel width; selecting a date shows combined daily input, output, cached and reasoning tokens, response count and cost instead of separate response rows.
- **Only real compaction shows a marker.** Ordinary context rewrites no longer appear as Context compacted. Real summaries remain visible; user messages stored only in old rewrite checkpoints are recovered for display without modifying logs.
- **Memory stays stable across steps.** Memory and Workspace instructions share a request header, preventing repeated Memory injection and unnecessary context growth.

## Other

- **Faster Usage loading.** Token-only Session and Project Thread summaries and daily/model aggregates are cached under ~/.tnega (or TNEGA_HOME). Unchanged histories reuse cached totals; log changes, deletion, pricing or timezone changes refresh affected data. Damaged caches rebuild automatically.
- **Categorized release notes.** GitHub notes and future release templates separate Features, Fixes and Other, omitting empty groups.

## Install

```bash
npm install -g tnega@0.4.16
```

Windows: download **Tnega-Setup-0.4.16.exe** from this release, or update through Settings → Check for updates. This is a stable release; use Settings → Update channel → Stable.

Session formats remain compatible; no migration is required. Usage caches are derived data and can be rebuilt without changing Session history. Close older desktop/CLI processes before using the updated client so both versions do not write to the same histories.
