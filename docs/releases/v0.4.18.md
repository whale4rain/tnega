# Tnega v0.4.18

## Features

- **Project chat bubbles.** User messages appear on the right and Agent messages on the left. Agents can send separate messages while working with send_project_message. Thread chat survives reloads; execution details stay folded.
- **Steer ordinary Sessions.** Send text or images during an active Run, including a Session running in another client. The Agent reads them at the next safe step without interrupting its tool or starting a concurrent Run. Stop remains available separately.

## Fixes

- **Reliable tray exit.** Exit closes native windows immediately and cleans up the runtime and embedded Browser. Cleanup failures and stalled shutdown or update installers have a ten-second exit deadline.
- **Instructions fit small windows.** Settings navigation preserves button height in short windows and wraps in narrow windows; long instruction text stays inside its panel.
- **Active Project coordination.** Coordinator guidance now prioritizes starting or reusing Threads for investigation, implementation and multi-step work. Ordinary Agents are encouraged to delegate useful independent work.
- **Stop or correct Project Agents.** Main and Thread composers retain asynchronous sending alongside Stop and Interrupt and send. Stopping the coordinator leaves other Threads running; replying to a Thread targets its own controls. Corrections enter the durable inbox before cancellation so pending input is preserved.

## Other

- **Reliable Windows test cleanup.** Question Web tests retry transient directory locks and release all fixture resources once, preventing one cleanup error from cascading into later server-close failures.

## Install

```bash
npm install -g tnega@0.4.18
```

Windows: download **Tnega-Setup-0.4.18.exe** from this release, or let an installed client update itself (Settings → Check for updates).

This is a stable release. Session formats remain compatible; optional Box interruption metadata and the additional Thread chat snapshot field require no migration. Stopping a Run does not undo completed tool effects. Close older desktop/CLI processes before using the updated client.
