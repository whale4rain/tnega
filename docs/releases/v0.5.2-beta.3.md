# Tnega v0.5.2-beta.3

## Fixes

- Reaching the top of a long session now loads the previous page by itself
  instead of asking with a button. The reader keeps their place while older
  messages prepend, and a page that does not fill the window keeps loading
  until the transcript can scroll or the history ends.
- Glass everywhere now reads as glass. The tinted backdrop shows through the
  conversation surface instead of being hidden behind it, and menus, the model
  list and other popovers that open inside a glass shell use a solid raised
  surface, so the content behind them no longer shows through their text.

## Install

```bash
npm install -g tnega@0.5.2-beta.3
```

Windows: download **Tnega-Setup-0.5.2-beta.3.exe** from this release, or select
the Preview update channel.
