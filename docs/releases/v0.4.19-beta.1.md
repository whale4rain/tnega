# Tnega v0.4.19-beta.1

## Features

- **Open Agent exchanges.** Compact Messaged receipts open a Workbench chat for
  the selected pair of Agents. Read separate messages from both participants,
  follow nested Thread exchanges and reopen restored history after reload.
  Participant avatars open their Thread chats.
- **Clickable message references.** File paths in Project, Thread and Agent
  exchanges open the Workbench. Ordinary Session user messages now support the
  same references. Local websites open Browser; external websites remain links.
- **Concise coordination.** Project coordinators and Threads are guided to send
  one topic per message, usually in 1–3 sentences, with useful constraints,
  blockers, verified outcomes and file or website references.

## Fixes

- **Smaller, tighter conversations.** Projects, Sessions and the Workbench share
  reduced typography. Message bubbles have softer backgrounds and tighter
  spacing; hidden reply buttons no longer reserve an empty line.

## Other

- **Local incremental E2E.** Optional browser checks cover chat rendering,
  exchanges, references, restored history, both themes and narrow windows.
  Run `pnpm --filter @tnega/web test:e2e`; these checks are not added to CI.

## Install

```bash
npm install -g tnega@0.4.19-beta.1
```

Windows: download **Tnega-Setup-0.4.19-beta.1.exe** from this release, or select
Preview in Settings → Update channel and check for updates.

This is a preview release, published to npm's `preview` channel. Existing
Sessions and Projects remain compatible; the additional Agent-message snapshot
field requires no migration. Existing message text is preserved. Concise
messaging is Agent guidance rather than a hard length limit.
