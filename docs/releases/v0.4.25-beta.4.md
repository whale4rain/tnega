# Tnega v0.4.25-beta.4

## Features

- On the desktop, while the right panel is open, the header actions sit in the top row beside the window controls, with the panel's tabs on the row below.
- Project rows show a project icon, the status light and a pull-request mark coloured by its current state (read with your own `gh` login). Git cards and Board chips show the current state too.
- Pinned folds and shows 8 projects plus "N more"; projects waiting on you or failed always stay visible. A project's "…" menu can archive, restore or delete it.
- Carbon, a new default theme: calm neutral greys with an ink accent, in light and dark. A palette you chose earlier is kept. The app icon is a white cloud on a dark tile.
- The Workbench is a rounded card inset from the window edges.
- New bundled fonts: Geist and Noto Sans SC for the interface, JetBrains Mono for code, and a Fraunces serif for greetings.
- The Project Board opens with a greeting, a plain-sentence status and a one-line recap, and its cards and sections are quieter.

## Fixes

- Switching workspaces or reopening a project no longer blanks the sidebar or the project screen while the new data loads.
- Collapsed workspace groups no longer show counts.
- A pull request opened as a draft shows as a draft instead of "Opened".

## Other

- Pull request state needs the GitHub CLI (`gh`) signed in; without it, the state recorded when the pull request was opened is shown.

## Install

```bash
npm install -g tnega@0.4.25-beta.4
```

Windows: download **Tnega-Setup-0.4.25-beta.4.exe** from this release, or select the Preview update channel.
