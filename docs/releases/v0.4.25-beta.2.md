# Tnega v0.4.25-beta.2

## Features

- Nunito, a rounded typeface bundled with the app, with the type ramp half a step larger.
- A wider left sidebar with taller rows and larger icons and titles.
- A wider Workbench that shares the conversation background; Project panels run edge to edge with clearer headings.
- Project artifacts open as a page on a near full-window sheet beside their Thread.
- Coordinator messages to a Thread appear in its chat as a dashed, labelled bubble.

## Fixes

- Windows desktop no longer freezes ("Not Responding") the first time a workspace is sandboxed for writes. The workspace-wide permission grant now runs in a separate helper process, and concurrent commands share one grant.
- The Windows ACL lock now fails closed after 5 minutes instead of waiting forever on a stuck holder.

## Other

- The grant fix has not yet been exercised on Windows beyond the release workflow's Windows test run; please report any freeze or sandbox error on first use of a large workspace.

## Install

```bash
npm install -g tnega@0.4.25-beta.2
```

Windows: download **Tnega-Setup-0.4.25-beta.2.exe** from this release, or select the Preview update channel.
